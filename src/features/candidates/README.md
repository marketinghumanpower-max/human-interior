# Feature: Candidates

Module quản lý ứng viên (danh sách ứng viên, chi tiết hồ sơ ứng tuyển, trạng thái tuyển dụng).

## Structure
- `api/`        — API functions (`candidatesApi.ts`).
- `hooks/`      — TanStack Query & Mutation hooks (`useCandidatesQuery.ts`).
- `components/` — UI components cho candidates (`CandidatesPage.tsx`).
- `types.ts`    — Domain types & DTOs cho Candidate.
- `index.ts`    — Public API re-export cho Feature module.
